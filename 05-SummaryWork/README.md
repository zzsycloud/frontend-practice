
# 光影摄影社 · 综合平台

本项目由平时大作业中的三个前端小作品整合而成，统一为「摄影社」主题、共享同一套导航与样式，构成一个完整的大作业。

## 目录结构

```
摄影社综合平台/
├── index.html        # 招新首页（展示 + HTML5 表单，整合自 03-SummaryHomework）
├── works.html        # 作品管理系统（增删查/搜索/本地存储/导出，整合自 mine）
├── stats.html        # 外拍费用统计工具（数据清洗/校验/排序/汇总，整合自 TheJavaScript）
├── css/
│   └── style.css     # 三个模块共享的样式表
├── js/
│   ├── works.js      # 作品管理逻辑
│   └── stats.js      # 费用统计逻辑（保留控制台输出，并新增页面展示）
└── README.md
```

## 三个模块与大作业要求的对应关系

| 模块                           | 对应作业考点                                                       |
| ------------------------------ | ------------------------------------------------------------------ |
| 招新首页 index.html            | HTML5 表单与多种表单控件、表单验证属性                             |
| 作品管理 works.html / works.js | DOM 操作、事件处理、增删查、搜索筛选、本地存储、导出 JSON          |
| 费用统计 stats.html / stats.js | 数组/对象/JSON 数据、核心函数、正则校验、reduce/sort、异常与健壮性 |

## 运行方式

直接用浏览器打开 `index.html` 即可（三页之间通过顶部导航栏互相跳转）。
统计页按 `F12` 打开控制台可查看 `console.table` 的完整输出。
